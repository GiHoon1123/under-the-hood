# Under the Hood

소프트웨어가 겉으로 드러난 API 뒤에서 실제로 어떻게 동작하는지 공부하고 기록하는 저장소입니다.

Node.js 코어와 libuv를 시작으로, 런타임, 운영체제, 네트워크, 데이터베이스, 메시징 시스템, 블록체인 등 다양한 기술의 내부 구조를 다룹니다.

이 저장소의 글은 완성된 튜토리얼보다 공부 과정에 가깝습니다. 소스 코드를 직접 읽고, 동작을 재현하고, 실험한 결과와 이해한 내용을 Markdown으로 정리합니다.

## 글을 정리하는 방식

각 주제는 특정한 순서에 묶어두지 않습니다. 공부하다가 관심이 생긴 부분을 먼저 살펴보고, 나중에 전체 구조 안에서 다시 연결합니다.

문서에는 가능한 한 다음 내용을 함께 남깁니다.

- 이 기능이 해결하는 문제
- 관련된 코드와 파일
- 실제 동작 흐름
- 운영체제 또는 런타임과의 관계
- 직접 실행한 실험과 테스트
- 처음 예상과 달랐던 부분
- 이해한 내용과 아직 남은 질문

## 저장소와 블로그

이 저장소는 공부 중인 내용을 먼저 정리하는 공간입니다.

나중에 내용이 충분히 정리되면 일부 글을 다듬어 블로그에 게시할 수 있습니다. 따라서 이곳의 문서는 블로그 글보다 덜 다듬어져 있을 수 있으며, 학습 과정에서 생긴 메모와 시행착오도 그대로 남깁니다.

## 목표

특정 라이브러리의 사용법만 익히는 것을 넘어, 코드가 실제로 어떤 계층을 거쳐 실행되는지 이해하는 것을 목표로 합니다.

```text
API
→ 런타임
→ 바인딩
→ 시스템 라이브러리
→ 운영체제
```
